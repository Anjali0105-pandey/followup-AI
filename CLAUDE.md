## Resume / PDF generation

Whenever generating a PDF for the user (e.g. a resume), always:
- Include an ATS (Applicant Tracking System) compatibility score alongside the output.
- Include a LinkedIn referral request message the user can send to a contact.
- If the ATS score comes out below 80, do not stop there — revise the resume content and re-score it, repeating until the score is 80 or higher (aim for as close to 100% as possible). Never hand back a final resume with an ATS score below 80.
